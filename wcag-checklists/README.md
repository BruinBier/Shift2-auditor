# WCAG-checklists

Referentiemateriaal voor Claude bij het uitvoeren van WCAG 2.2-audits op gemeentelijke websites en PDF-documenten.

## Wat staat hier

- **`Project_Instructie_WCAG_Audit.md`** — De projectinstructie: rol, werkwijze, bevindingformat, schrijfstijl. Start hier.
- **`Checklist_SC_X_X_X.md`** — Per succescriterium (SC) een gedetailleerde checklist met definitie, auditgebieden, beslisboom, voorbeelden en rapportageformat.
- **`Richtlijnen_Grensgevallen_SC_X_X_X.md`** — Beslisregels voor grensgevallen per SC (bijv. logo als linkinhoud, teaserfoto's in overzichten).
- **`Voorbeelden_Bevindingen.md`** — Referentievoorbeelden voor schrijfstijl, toon en structuur van bevindingen.

## Hoe Claude dit gebruikt

Bij de opdracht "Controleer SC X.X.X op [URL]":

1. Lees `Project_Instructie_WCAG_Audit.md` voor de werkwijze.
2. Lees de relevante `Checklist_SC_X_X_X.md`.
3. Raadpleeg `Richtlijnen_Grensgevallen_SC_X_X_X.md` als die bestaat.
4. Gebruik `Voorbeelden_Bevindingen.md` voor schrijfstijl.
5. Schrijf bevindingen conform het format.
6. Log de bevindingen via de audit-CLI (zie `CLAUDE.md`, sectie "Audit CLI").
